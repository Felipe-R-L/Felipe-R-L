### 👨‍💻 About Me

🇧🇷 **Backend & Platform Engineer** building real-time, multi-tenant SaaS for precision agriculture. I take systems from the **device all the way to the dashboard** — ingestion pipelines, time-series data, cloud infra, and the UI on top.

- 🛰️ I work with **high-throughput telemetry**: MQTT, queues, time-series storage and BI aggregations at scale.
- 🧱 I care about **architecture** — Clean Architecture, DDD and SOLID — and about systems that stay fast as data grows.
- ☁️ Going deeper on **platform engineering**: infra-as-code, observability and system design.
- 🌐 Fluent in **English (C2)**, comfortable working directly with international clients and stakeholders.

🔭 **Currently building:** an open-source real-time telemetry platform — *MQTT → queue → time-series → API → live dashboard* — provisioned with Terraform. *(coming soon)*

---

### 💼 Experience

**Fullstack / Platform Developer @ OMD do Brasil** · *Aug 2024 – Present*

Core developer on a **multi-tenant precision-agriculture SaaS** that ingests and visualizes planting telemetry from sugarcane fields.

- ⚡ Cut BI query times from **30s+ to under 2s** with TimescaleDB read models and indexing strategies.
- 🛰️ Built **"Uber-style" live machine tracking** over MQTT and orchestrated high-throughput ingestion with BullMQ.
- 🗺️ Shipped advanced map features (raw points + aggregated heatmaps) with the Google Maps API and weather layers.
- 🏗️ Set up **CI/CD** (GitHub Actions + Cloud Build) and Docker across dev/staging/prod, and helped migrate the codebase to an **Nx monorepo**.
